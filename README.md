# 101487075_comp3123_labtest2
This is my weather app for COMP3123 Lab Test 2. The application shows the current weather and a 5-day forecast using OpenWeatherMap.

## What the App Does
->Search weather by any city
->Shows today’s weather with an icon
->Shows extra details (humidity, feels like, wind, etc.)
->Shows a 5-day forecast (side-by-side cards)
->Responsive and clean UI

# APIs Used
OpenWeatherMap Current Weather API https://openweathermap.org/
5-Day Weather Forecast API

# How to Run

->Download or clone the project
-> Run npm install
->Add your API key inside App.js

# Run:
->npm start
